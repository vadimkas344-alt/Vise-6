# Vise-6

An original open-world action-driving prototype made with Godot 4. It takes broad inspiration from open-world city games; it is not Grand Theft Auto VI and does not use Rockstar assets.

## Target PC
- AMD Ryzen 5 1600
- NVIDIA GeForce GTX 1050
- 16 GB DDR4 RAM

## Graphics and performance
- Godot 4 Compatibility renderer for older GPUs.
- Procedural city blocks, colored building materials, a sunny sky and directional shadows.
- Start at 1280x720. Try low shadow quality if frame rate drops.
- No ray tracing or heavy Lumen-style effects.

## Controls
- WASD: move / drive
- Mouse: look around
- Shift: run
- Space: jump / brake in car
- E: enter or exit the nearby car
- Esc: release mouse

## Run and build
Open this folder in Godot 4.4.1 and run the main scene. GitHub Actions automatically exports a Windows x86_64 executable and uploads it as the `Vise-6-Windows` artifact when the build succeeds.

This is an early playable prototype foundation, not a finished commercial-scale game.
